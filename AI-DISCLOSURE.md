This project is **an AI-agent workflow, and it was built by one.** Read this before you run it.

## What it is

`wp-archiver` is a set of [agent skills](https://docs.claude.com/en/docs/claude-code/skills) plus a script toolkit. It instructs an AI coding agent (developed and exercised with [Claude Code](https://claude.com/claude-code)) to archive a WordPress site as a static site: it runs shell commands, Docker containers, a headless browser and database scripts **on your machine**, using the permissions you give the agent.

## How it was made

- The workflow was first worked out in a real, agent-driven archive of one site (Claude Code, with the site owner making every decision and running every deploy). The mistakes made along the way are recorded in [`skills/wp-archiver/reference/case-study.md`](skills/wp-archiver/reference/case-study.md).
- This repository was then **extracted and generalised by an AI agent** (Claude) from that run's playbook and scripts: site-specific values became `.env` settings, the Elementor-specific parts were isolated as a builder adapter, and the documentation was rewritten as skills.
- The human maintainer set the direction, supplied the original run, and reviews what is published. Commits made with agent help carry a `Co-Authored-By` trailer.

## Using it safely

- **Review before you approve.** The agent will propose commands that delete files, drop database tables and copy `wp-config.php`-bearing archives around. Read them. Work on copies; keep your own backup of the original host download.
- **Keep the owner in the loop.** The skills tell the agent to stop and ask before `git push`, `wrangler deploy`, DNS changes and deleting anything from the raw download. That guardrail is a prompt, not a sandbox: it depends on you running the agent with permission prompts on.
- **Secrets.** The raw download contains database credentials, salts, private keys and visitor data. The skills keep it out of git by design, but only you can check what you publish. Run a secret scanner before pushing a site repo.
- **Only archive sites you own or are authorised to archive.**
- AI-generated output can be wrong. Where this repo says "proven", it means "checked against a measured reference in the reference run", not "guaranteed".
